📚 智库 — Query Intelligencer

DISCOVER → CALIBRATE → DEDUPE → VERIFY

Mission: Discover what sellers actually search on AI engines. Produce a validated, precise query library.

Input: SEO/SEM keywords, AI platform reverse-extraction, community/CS real questions, official site search terms, AlsoAsked/AnswerThePublic, seller lifecycle projections (Forecaster), policy change predictions

Process:

① Multi-source query generation (7 sources in parallel)
② 3-dimension calibration: Cross-platform consensus · 35-category matching · Timeliness check
③ Semantic deduplication (>85% similarity = merge)
④ 7-platform live validation via 智测

Output: zhiku_ai_queries.csv — validated search phrases with source, accuracy score, category, selection status

Platforms: CN: DeepSeek, Doubao, Yuanbao, Qianwen, Kimi · WW: ChatGPT, Gemini

Key Metric: 564 validated queries (Q2), +90% vs Q1

🔍 智测 — AI Coverage Tester

SIMULATE SEARCH JOURNEY → DETECT GAPS → TRACK COMPETITORS

Mission: Verify our content coverage across 7 AI platforms. Identify gaps, competitor presence, and sentiment.

Input: Validated queries from 智库

Process:

① Execute real search on each platform per query
② Detect: brand/product mention, official link presence, competitor mentions
③ Classify: covered / partial_gap / full_gap
④ Analyze: content sentiment (positive/neutral/negative toward Amazon)

Output: gap_result_{timestamp}.csv — per-query × per-platform gap status, competitors found, sentiment

Detection Logic: Brand keywords (亚马逊/Amazon/Global Selling/FBA/Seller Central...) + Competitor keywords (Shopee/Lazada/TikTok Shop/Alibaba/eBay/Walmart/Temu/Shopify)

Tracking: Cumulative prompt_tracking_history.csv for brand mention rate trends over time

✍️ 智造 — Content Creator

QUERY → PERSONA × TEMPLATE → GEO-OPTIMIZED ARTICLE

Mission: Batch-produce GEO-optimized content that AI engines will cite.

Input: Selected queries from 智库 + Knowledge base (18 category docs) + Reference materials

Process:

① Match query to persona (6 seller personas × lifecycle stages)
② Select template: auto-detect by keywords (registration/fees/logistics/advertising/listing) or freeform
③ RAG: retrieve relevant knowledge from official source URLs
④ Generate: 800-1500 word article, structured for AI readability (short paragraphs, lists, FAQ)
⑤ Anti-hallucination: Critical=5 categories enforce "3 iron rules" — read official only, summarize only, no interpretation

Output: zhizao_draft_content.csv — title, content_draft, ai_query, word_count, version

Capacity: 50-80 articles per batch · ~170/month (vs Q1: ~86/month)

Template System: 35 content categories, each with designated official source URLs. 6 Critical=5 categories (registration, fees, audit, VAT, tax, compliance) have strictest constraints.

🔧 智优 — Quality Optimizer

SCORE → REWRITE → COMPLIANCE → APPROVE

Mission: Ensure every article meets quality threshold. Auto-fix those that don't.

Input: Draft articles from 智造

5-Dimension Scoring:

• Intent Match (30%) — Does it directly answer the AI query?
• AI Readability (20%) — Easy for AI to parse? Clear structure?
• Authority (20%) — Verifiable info? Platform-specific knowledge?
• Actionability (20%) — Clear next steps? Executable guidance?
• Differentiation (10%) — Unique vs generic? Would AI prefer this?

Pass Threshold: overall_score ≥ 4.5 AND intent_match ≥ 4 AND authority ≥ 4

Auto-Rewrite: Below threshold → rewrite with scorecard suggestions → re-score → loop until pass

Compliance: Prohibited terms check (竞品名/个人销售计划/...) + Link validation (must be amazon domain) + Official info consistency

Output: zhiyou_optimized_content.csv + zhiyou_scorecard.csv

Result: 29/35 categories fully automated (AI-only). 6 high-risk categories: POC spot-check only (no longer per-article review).

📦 智布 — Publisher

OPTIMIZED CONTENT → STRUCTURED JSON + WORD DOC

Mission: Convert optimized articles to CMS-ready structured format with full traceability.

Input: Optimized content from 智优

Output Structure (JSON):

• meta: title, description, keywords
• body: full optimized article
• ai_friendly: 5-dimension scores + overall
• compliance: status (PASS/FIXED), disclaimer, copyright
• source_keywords: original query traceability

Additional Output: Word document (.docx) for offline review and manual CMS upload
