# Smart Suite Agent Routing — 意图识别与执行路由

> 当用户用自然语言描述需求时，自动识别意图并路由到正确的智系列模块执行。
> 本规则始终生效，确保 Kiro 在任何对话中都能准确调度智系列工具链。

## 执行规则

### 1. 智造（内容生产）

当识别为"智造"意图时：

```
1. 确认要生成的检索短语（用户指定 or 从智库选中列表取）
2. 确认内容类别（对应 content-rules.md 的 35 个类目）
3. 查找该类目的 Content Source URL
4. 按类目 Critical 等级选择约束：
   - Critical 5: 只能总结官方信息，禁止发挥
   - Critical 3-4: 可适度补充行业通识
5. 按 SEO+GEO 标准生成内容（参考 smart-suite-phase1.md）
6. 必须包含：≥1表格、≥2列表、≥3 FAQ、≥2次 gs.amazon.cn 链接、≥800字
7. 首段给直接答案，H2 下先结论后展开
8. 生成后自动做一次 content-writing-compliance 检查
```

### 2. 智优评分

当识别为"评分"意图时：

```
1. 读取待评分内容
2. 按 5 维度打分（1-5分）：
   - Intent Match（30%）: 是否直接回答查询
   - AI Readability（20%）: AI 是否容易解析
   - Authority（20%）: 是否权威可靠
   - Actionability（20%）: 是否可操作
   - Differentiation（10%）: 是否有差异化
3. 计算加权总分
4. 如总分 ≥ 4.5 且各项 ≥ 4 → 通过
5. 给出具体优化建议（不是模糊的"需要改进"）
```

### 3. 合规审查

当识别为"合规"意图时：

```
1. 执行 content-writing-compliance.md 的 10 项 checklist
2. 执行 pre-legal-self-check.md 的 4 层检查
3. 输出格式：
   - PASS: 无问题
   - WARNING: 需人工确认（标明位置+建议）
   - BLOCKED: 必须修改（标明位置+修改方案）
4. 对 BLOCKED 项自动给出修改后的文本
```

### 4. 智测（AI 搜索模拟）

当识别为"智测"意图时：

```
1. 确认检索短语（用户提供 or 从智库取）
2. 确认平台（默认全平台，或用户指定）
3. 对每个短语执行 web search
4. 分析返回结果：
   - 是否出现官网链接（gs.amazon.cn）
   - 竞品信源有哪些
   - 内容质量如何
5. 输出覆盖率报告
```

### 5. 智中枢（决策）

当识别为"决策"意图时：

```
1. 读取最新智析数据（steering 中的 weekly_report）
2. 逐条检查 7 条决策规则
3. 标记触发的规则
4. 生成周计划（加速/监控/排查 + 具体任务列表）
5. 输出标准格式
```

## 对话风格

- 识别到明确意图时 → 直接执行，不多问
- 意图不明确时 → 简短追问一次（"你想对哪篇内容做合规检查？"）
- 执行完后 → 简洁总结结果，问"还需要什么？"
- 多步骤任务 → 每步完成后汇报进度
