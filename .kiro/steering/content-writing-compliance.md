# 内容写作合规规范 — 智造/智优生产时强制执行

> 本文档定义内容生产阶段的前置合规约束。智造生成内容时必须遵守，智优优化时必须验证。
> 目标：在生产时就消除合规风险，而非事后审核再修改。

---

## 一、禁用词替换表（硬性规则，无例外）

生成内容时遇到以下词汇，**必须自动替换**，不得保留原词：

| ❌ 禁止使用 | ✅ 应替换为 | 适用场景 |
|------------|-----------|---------|
| 市场 / 细分市场 | 站点 / 国家 / 地区 / 行业 | 描述 Amazon 各站点时 |
| 平台 / 亚马逊平台 | 网站 / 站点 | 描述 Amazon 时（"卖家平台"除外） |
| 生态 / 生态系统 / 生态圈 | 服务 / 产业服务集群 | 描述 Amazon 服务体系时 |
| 最好 / 最佳 / 顶级 / 第一品牌 | 领导者 / 最好的选择之一 / 优选 | 任何评价性语境 |
| 最佳实践 | 实践分享 / 推荐做法 | 经验分享语境 |
| 保证 / 确保 / 一定能 / 必定 | 帮助 / 目标是 / 有助于 | 描述效果/结果时 |
| 显著提升 / 大幅增长 | 有助于提升 / 可能带来改善 | 描述工具/功能效果时 |
| 合作伙伴 | 第三方服务提供商 | 描述非 Amazon 实体时 |
| 伙伴 / 合伙关系 / 联盟 | 建立合作 / 签署合同 | 描述商业关系时 |
| 最终解释权归亚马逊所有 | 亚马逊保留对本项目/活动的解释权 | 活动条款中 |
| 招商 / seller recruiting | 卖家拓展 / 卖家宣传 | 描述业务活动时 |
| 销售(sales) / 协议定价 | 建议 / 咨询 / 支持 / 协助 | 描述团队活动时（Tax 口径） |
| 致命错误 | 常见严重错误 | 描述风险时 |

## 二、第三方服务商提及规则

### 铁律：不得单独推荐具体服务商

| 规则 | 说明 |
|------|------|
| ❌ 禁止点名推荐 | 不可写"推荐使用 Jungle Scout"、"建议用连连支付" |
| ❌ 禁止暗示官方背书 | 不可写"官方认可/指定/合作服务商" |
| ✅ 可以泛化提及 | "可使用第三方选品分析工具辅助决策" |
| ✅ 如需举例必须加声明 | 列举多个工具名时，必须附加免责声明 |

### 举例场景的标准写法

**错误写法：**
> 建议使用连连支付或PingPong，费率更低。

**正确写法：**
> 建议使用第三方跨境收款工具（市面有多家可选），费率通常低于银行电汇。

**如果业务确实需要举例（不推荐）：**
> 市面常见的选品工具包括 A、B、C 等（以下仅为举例，非亚马逊官方推荐或背书，请自行评估选择）。

## 三、品牌与平台名称使用规范

### 3.1 全球开店 vs 亚马逊 vs Seller Central

| 实体 | 正确用法 | 错误用法 |
|------|---------|---------|
| gs.amazon.cn | "亚马逊全球开店页面" / "全球开店官方页面" | ❌ "亚马逊卖家平台（gs.amazon.cn）" |
| Seller Central | "亚马逊卖家平台（Seller Central）" | ❌ "全球开店后台" |
| 境外产品/工具 | 服务提供方 = "亚马逊" / "亚马逊XX站" | ❌ "全球开店推出X工具" |
| 注册流程 | "通过亚马逊卖家平台完成注册" | ❌ "前往全球开店官网注册" |
| 审核主体 | "亚马逊将审核" | ❌ "我们将审核" / "我们的要求" |

### 3.2 核心规则
- **全球开店** = 中国团队本地化服务品牌（负责卖家教育、宣传）
- **亚马逊 / Amazon** = 境外站点产品和服务的提供方
- 描述 FBA、Brand Registry、Sponsored Products 等产品时，主语必须是"亚马逊"
- 不得在境外产品品牌前加"全球开店"logo 或名称

### 3.3 Copyright 标准格式

```
Copyright © 2026 Amazon.com, Inc. or its affiliates. All rights reserved.
```

注意：`reserved` 小写 r，主体为 `Amazon.com, Inc. or its affiliates`。

## 四、数据与声明规范

### 4.1 费率/数据引用规则

| 场景 | 规则 |
|------|------|
| 引用官方公开费率 | ✅ 允许，但必须标注来源 + 时效 |
| 引用内部数据 | ❌ 禁止（除非已公开在股东信/财报中） |
| 引用第三方数据 | 必须标明出处 + 加 disclaimer |
| 给出具体数字但无来源 | ❌ 禁止 |

### 4.2 费率引用标准写法

**错误：**
> 月租仅需支付一次（39.99美元）。

**正确：**
> 专业卖家账户月费为 39.99 美元（以亚马逊卖家平台最新公告为准）。

### 4.3 佣金/费用范围

- 佣金因品类差异较大时，必须给出范围而非单一数字
- **错误：** "亚马逊佣金（15%）"
- **正确：** "亚马逊销售佣金因品类不同通常在 8%-15% 之间（具体参考卖家平台费率页面）"

### 4.4 效果性声明

- 禁止给出无来源的具体百分比
- **错误：** "A+页面可提升转化率 5-10%"
- **正确：** "A+页面有助于提升转化表现"（如需数字，必须标注来源）

### 4.5 强制 Disclaimer

所有内容**文末必须**包含以下免责声明（根据内容类型选择对应版本）：

**通用版（Critical 3-4）：**
> 本文仅供参考，不构成商业承诺。实际结果因情况而异，所有费率和政策以亚马逊卖家平台最新公告为准。

**费用/注册类（Critical 5）：**
> 本文所述费率及政策信息来源于亚马逊卖家平台公开资料（截至 [年份]），仅供参考，不代表亚马逊的正式承诺或建议。实际费用以卖家后台最新公告为准。

## 五、绝对化/保证性陈述规则

### 5.1 禁止保证性承诺

| ❌ 禁止 | ✅ 替代 |
|--------|--------|
| 确保你在X天内达成Y | 帮助你在X天内尝试达成Y |
| 保证增长 / 保证出单 | 有助于提升机会 |
| 100% 安全 / 一定能 | 相对安全 / 通常可以 |
| X决定成败 | X是成功的关键因素之一 |
| 显著提升转化率 | 有助于提升转化率 |

### 5.2 限定性表述豁免

以下表述已自带限定，不触发告警：
- "之一" / "可能是" / "相对较" / "通常" / "在多数情况下"

## 六、注册引导专项规则（Tax 合规重点）

| 规则编号 | 内容 |
|---------|------|
| T1 | 注册引导必须明确说明"通过亚马逊卖家平台注册"，不得写"前往全球开店官网注册" |
| T2 | 禁止"扫码注册"类导向 leads form 的表述 |
| T3 | 审核主体必须是"亚马逊"，不得用"我们" |
| T4 | gs.amazon.cn 只能描述为"全球开店页面/入口"，不能称为"卖家平台" |
| T5 | 介绍境外站点的产品/工具时，品牌主体为"亚马逊"或"亚马逊XX站" |

## 七、竞品与敏感话题

### 7.1 竞品规则
- ❌ 禁止与任何友商进行对比（"比XX好"、"优于XX"、"vs XX"）
- ✅ 只能突出亚马逊自身优势和特点
- 已在 Global Prohibited Terms 中禁止的平台名（Shopee/Lazada/TikTok/速卖通/eBay）同样适用

### 7.2 地区敏感表述
- 台湾 → 必须写"中国台湾"
- 香港 → 必须写"中国香港"
- 澳门 → 必须写"中国澳门"
- ❌ 禁止评论国际关系、政治议题、COVID商机

## 八、智造生产时的 Checklist（自动执行）

生成每篇内容后，智造/智优必须自动校验以下清单：

```
□ 1. 无禁用词（第一节替换表全部检查）
□ 2. 无第三方服务商点名推荐（或已加免责声明）
□ 3. 品牌名称使用正确（全球开店 vs 亚马逊 vs Seller Central）
□ 4. 所有费率数据有来源标注 + 时效声明
□ 5. 无保证性/绝对化承诺
□ 6. 无未标注来源的具体效果百分比
□ 7. 文末包含 Disclaimer
□ 8. Copyright 格式正确
□ 9. 注册引导符合 Tax 规则（T1-T5）
□ 10. 无竞品对比/敏感话题
```

任何一项未通过 → 必须自动修正后再输出，不得带着问题交付。
