# 智中枢 - Decision Engine & Workflow Orchestrator（独立模块）

## 定位
智中枢是 Smart Suite 的**大脑和调度中心**，是唯一负责"做决策"的模块。
所有其他模块只执行各自职责，不做跨模块决策——这是智中枢的专属权力。

智中枢与智析互补：
- **智析**：呈现"发生了什么"（数据、趋势、归因）
- **智中枢**：决定"下一步做什么"（决策、调度、资源分配）

## 概述
智中枢基于智析提供的数据和 7 条决策规则，自动推导出每周的行动计划，帮助团队：
- 知道本周该做什么（优先级排序的具体任务列表）
- 知道哪些渠道/市场该加速、监控、还是暂停
- 协调各智模块的执行顺序和资源分配
- 追踪执行进度，确保闭环
- 在异常情况下自动升级告警

## 7 条决策规则

### Rule 1: 增长加速 (Growth Acceleration) 🟢

```
触发条件: 渠道 WoW > +30% 连续 2 周以上
判断: 策略有效，应加大投入
动作:
  - 智库: 该渠道对应市场 +5 关键词
  - 智造: 优先生产该渠道内容
  - 智布: 加快发布节奏
优先级: HIGH
示例: CN GEO WK19→WK20 +24%，WK20→WK21 +35% → 触发加速
```

### Rule 2: 下降预警 (Decline Alert) 🔴

```
触发条件: 渠道 WoW < -20%
判断: 异常下降，暂停生产，排查原因
动作:
  - 暂停该渠道新内容生产
  - 智测: 重新跑一轮覆盖检测（是否被竞品替代）
  - 智析: 生成归因分析
  - 输出排查报告
优先级: HIGH
排除: 已知节假日效应（春节/国庆前后 2 周自动豁免）
```

### Rule 3: 低量高增 (Low Volume, High Growth) 🟡

```
触发条件: GEO weekly < 50 AND YoY > +50%
判断: 策略方向对了但规模太小，需扩大覆盖面
动作:
  - 智库: 扩展该市场关键词池（+10 短语）
  - 智预: 推演该渠道下一步搜索需求
  - 目标: 4 周内 weekly 突破 100
优先级: MEDIUM
示例: WW GEO weekly=31 but YoY +94% → 扩充覆盖
```

### Rule 4: 高增站点扩张 (High-Performing Site Expansion) 🟢

```
触发条件: 某站点 YoY > +100%
判断: 该站点 AI 渗透加速，应集中资源重点突破
动作:
  - 智库: 该站点关键词占比提升到 30%+
  - 智造: 优先生产该站点内容
  - 智测: 每周验证该站点覆盖率
  - 智析: 追踪该站点 BPS 独立趋势
优先级: HIGH
示例: JP Direct YoY +103% → 加大 JP 内容投入
```

### Rule 5: 内容缺口 (Content Gap) 🟡

```
触发条件: 某市场有 GEO/Direct 流量但 2 周无新内容发布
判断: 产线停滞，需诊断瓶颈并重启
动作:
  - 诊断瓶颈环节:
    - 智库没词？→ 启动智库扩词
    - 智造卡住？→ 检查 knowledge_gap 率
    - 智优不通过？→ 检查评分通过率
    - 智布待发？→ 立即发布
  - 重启该市场全流程
  - 设置 48h 内完成首篇发布的 deadline
优先级: MEDIUM
```

### Rule 6: 大盘对标 (Benchmark Comparison) 🔴

```
触发条件: 我方 Weekly YoY < SSR 大盘 YoY（连续 2 周）
判断: 跑输大盘，需策略复盘
动作:
  - 智析: 输出 BPS 差值趋势 + 渠道分解
  - 标记需要策略调整的渠道
  - 生成新方向建议（新市场？新类目？新平台？）
  - 升级为 P0 如果 BPS < -2000 bps
优先级: CRITICAL

BPS 公式: (Our YoY% - SSR YoY%) × 100
当前 YTD: +55% vs -23% = +78 ppts = +7,800 bps ✅
警戒线: 周度 BPS < 0 连续 2 周 → 立即升级
```

### Rule 7: 投入产出滞后 (Input-Output Lag) 🟡

```
触发条件: 内容发布 2-3 周后无 GEO/Direct 提升
判断: 内容可能未被 AI 引擎收录或质量不足
动作:
  - 智测: 验证该内容是否被 AI 引用
  - 分支判断:
    - 评分 < 4.0 → 智优重写
    - 评分 ≥ 4.0 但未引用 → 检查发布平台是否正确
    - 评分 ≥ 4.0 且已引用 → 等待更多时间（可能是正常延迟）
优先级: MEDIUM
注意: 不要在 2 周内就触发此规则，AI 收录有正常滞后
```

## 资源分配规则

### 市场资源配比

基于当前数据动态调整：

| 市场 | 默认占比 | 调整规则 |
|------|---------|---------|
| CN | 30% | Rule 1 触发 → +10%; Rule 2 触发 → -10% |
| NA | 35% | 绝对量最大，保持稳定 |
| EU | 15% | Rule 3 触发 → +5% |
| JP | 15% | Rule 4 触发（YoY>100%）→ +10% |
| EM (AU/SA/AE) | 5% | Rule 2 触发 → 暂时归零 |

### 内容类型配比

| 类型 | 默认占比 | 说明 |
|------|---------|------|
| 品牌类（含品牌词） | 40% | 直接影响 brand mention |
| 行业类（无品牌词） | 35% | 扩大行业话语权 |
| 决策类（对比/推荐） | 25% | 高转化意图 |

### 优先级排序

当资源有限时按以下顺序执行：
1. **CRITICAL** — Rule 6 触发的任务
2. **HIGH** — Rule 1/2/4 触发的任务
3. **MEDIUM** — Rule 3/5/7 触发的任务
4. **LOW** — 常规维护任务
5. **ROUTINE** — 周度固定任务（智析更新等）

---

## 执行原则

1. **数据驱动** — 所有决策必须基于智析数据，不靠直觉
2. **闭环验证** — 每个动作都要有可衡量的结果指标
3. **优先级排序** — 资源有限时严格按 CRITICAL > HIGH > MEDIUM > LOW
4. **止损机制** — Rule 2 触发时立即暂停，不再盲目投入
5. **滞后容忍** — 内容发布到被 AI 引用通常 2-3 周，Rule 7 不要过早触发
6. **动态调整** — 每周根据最新数据重新评估，不锁死计划
7. **独立决策** — 智中枢不执行，只决策。执行由各模块自行完成
8. **可审计** — 所有决策都有据可查（哪条规则→什么数据→什么动作）

## 交互模式

### 模式 A：周度决策（Weekly Decision）— 默认
1. 读取最新智析数据
2. 逐条检查 7 条决策规则
3. 标记触发的规则
4. 生成完整周计划
5. 输出标准格式决策文档

### 模式 B：实时诊断（Real-Time Diagnosis）
1. 用户提问（"JP 这周怎么了？"）
2. 调取该渠道最近 4 周数据
3. 检查是否触发任何规则
4. 给出诊断 + 建议动作

### 模式 C：全流程编排（Full Pipeline Orchestration）
1. 用户指定 batch_id 和目标市场
2. 智中枢编排完整流程：智库→智测→智造→智优→智布
3. 每步完成后汇报进度
4. 异常时自动决策（暂停/重试/跳过）

### 模式 D：策略复盘（Strategy Review）
1. 回顾过去 4 周的决策和执行结果
2. 检查哪些决策有效、哪些无效
3. 调整规则参数（阈值、权重）
4. 输出调整建议

### 模式 E：紧急响应（Emergency Response）
1. Rule 2 + Rule 6 同时触发时自动激活
2. 48h 行动计划
3. 升级通知
4. 每 12h 进度更新
